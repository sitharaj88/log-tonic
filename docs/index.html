Quick Start

src/logger.ts
import { LoggerFactory, LogLevel, ConsoleTransport } from 'log-tonic';

// Initialize Global Config
LoggerFactory.initialize({
  minLevel: LogLevel.DEBUG,
  appName: 'MySuperApp',
  transports: [
    new ConsoleTransport({ useJson: true }) 
  ]
});

const logger = LoggerFactory.createLogger('AuthService');

// Log with metadata
logger.info('User logged in', { 
  userId: 'u-123', 
  session: 's-456' 
});

Migration Guide (v1.0.x -> v1.1.0)

⚠️ Breaking Changes

Version 1.1.0 introduces structured types and enterprise transports. To upgrade from v1.0.1:

  • Change level (string) to minLevel (Enum).
  • Import LogLevel from the package.
  • Replace string levels (e.g. "debug") with Enums (e.g. LogLevel.DEBUG).
Migration Example
// ❌ Old (v1.0)
LoggerFactory.initialize({
  level: 'debug',
  appName: 'App'
});

// ✅ New (v1.1)
import { LoggerFactory, LogLevel } from 'log-tonic';

LoggerFactory.initialize({
  minLevel: LogLevel.DEBUG, // Enum required
  appName: 'App'
});
